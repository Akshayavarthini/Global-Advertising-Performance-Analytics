# Global Ads Performance Dashboard

An interactive **Power BI dashboard** developed to analyze global digital advertising performance across platforms, campaign types, industries, countries, and time.

## Project Overview

This project analyzes advertising performance data to evaluate **advertising spend, revenue, clicks, conversions, campaign efficiency, and return on advertising spend (ROAS)**.

The dashboard transforms raw advertising data into interactive KPIs and visualizations for analyzing **platform performance, campaign effectiveness, industry trends, geographic performance, and advertising efficiency**.

## Data Analysis & Calculations

The dashboard uses **DAX measures** to calculate key advertising metrics.

- **ROAS** = Total Revenue / Total Advertising Spend
- **CTR** = (Total Clicks / Total Impressions) × 100
- **CPC** = Total Advertising Spend / Total Clicks
- **CPA** = Total Advertising Spend / Total Conversions
- **Conversion Rate** = (Total Conversions / Total Clicks) × 100

These calculations are used to measure campaign reach, engagement, acquisition cost, conversion efficiency, and advertising returns.
